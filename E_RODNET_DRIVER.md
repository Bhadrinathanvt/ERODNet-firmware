# e_rodnet Bare-Metal Driver

Bare-metal C driver for the `e_rodnet` CNN / radar object-detection IP on
the Yamuna Shakti SoC (SHAKTI C-Class, RV32IMAC). Ships as an add-on so
it is merged into every project generated by `create_shakti_project.sh`:

```text
add_ons/drivers/e_rodnet.c          --> <project>/drivers/e_rodnet.c
add_ons/include/e_rodnet.h          --> <project>/include/e_rodnet.h
add_ons/include/e_rodnet_regs.h     --> <project>/include/e_rodnet_regs.h
add_ons/include/platform.h          --> <project>/include/platform.h   (E_RODNET_BASE, PLIC_INTERRUPT_36..38)
```

## Hardware expected

| Interface              | Endpoint                                    | Notes                                                        |
|------------------------|---------------------------------------------|--------------------------------------------------------------|
| AXI4-Lite slave        | CSR (21 registers, offsets in `e_rodnet_regs.h`) | `E_RODNET_BASE = 0x0005_0000` on the slow-fabric bridge |
| AXI4 master            | DMA read from DDR3 (`0x8000_0000`)           | scatter-gather, programmed via `e_rodnet_dma_setup`          |
| AXI4 master            | DMA write of detection bursts                | beat = `{pad, class_id, conf, w_idx, h_idx}`                 |
| IRQs (3 × `irq_*`)     | PLIC sources 36 / 37 / 38                    | `frame_done`, `detection`, `error`                           |

## Using the driver

```c
#include "e_rodnet.h"
#include "plic_driver.h"
#include "uart.h"

static e_rodnet_handle_t rod;

int main(void) {
    init_uart();
    plic_init();

    e_rodnet_init(&rod, E_RODNET_BASE);

    e_rodnet_config_t cfg = {
        .temporal_mode   = E_RODNET_TMODE_TDC,    /* fork extension, see sec:tdc */
        .temporal_blend  = 0,
        .conv_channels   = 64,
        .conv_kernel     = 7,
        .conf_threshold  = 32,                    /* Q0.7 ~ 0.25 */
        .iou_threshold   = 64,                    /* Q0.7 ~ 0.50 */
        .top_k           = 20,
        .feature_h       = 128,
        .feature_w       = 128,
        .history_depth   = 8,
    };
    e_rodnet_configure(&rod, &cfg);

    e_rodnet_dma_desc_t dma = {
        .src_phys     = 0x80000000,   /* DDR3: RA heatmaps in  */
        .dst_phys     = 0x80400000,   /* DDR3: detection list out */
        .frame_size   = 128 * 128 * 16, /* HxWx(IN_C bytes)     */
        .frame_count  = 1,
        .loop         = 0,
    };
    e_rodnet_dma_setup(&rod, &dma);

    e_rodnet_irq_attach(&rod);
    e_rodnet_start(&rod);

    e_rodnet_wait_done(&rod, /*cycles timeout*/ 50'000'000);

    e_rodnet_det_t dets[20];
    size_t n = e_rodnet_read_detections((void *)dma.dst_phys, dets, 20);
    for (size_t i = 0; i < n; ++i) {
        printf("det[%u] cls=%u conf=%u @(h=%u,w=%u)\n\r",
               (unsigned)i, dets[i].class_id, dets[i].conf,
               dets[i].h_idx, dets[i].w_idx);
    }

    e_rodnet_deinit(&rod);
    return 0;
}
```

## Temporal modes

`cfg.temporal_mode` maps 1:1 to the `reg_temporal_mode[1:0]` CSR bits, with
the v3.2 fork-extension TDC encoding (see
`docs/chapters/ch02_network_architecture.tex`, section `sec:tdc`):

| Value | Meaning                            |
|-------|------------------------------------|
| 0     | None (single-frame)                |
| 1     | Temporal Fusion (weighted blend)   |
| 2     | Temporal Aggregation               |
| 3     | Fusion + Aggregation               |
| 4     | ConvLSTM                           |
| 5     | **Temporal Deformable Conv (TDC)** |

The RTL wrapper (`e_rodnet_axi_top.sv`) truncates this to 1 bit today
(WRAPPER-003) - the driver still ships the full encoding so that, once
the wrapper is widened, no software changes are needed.

## Known wrapper issues that affect the driver

- **WRAPPER-001 (CRITICAL)** - CSR writes are on `clk_axi` but the accelerator
  runs in `clk`; there are no synchronizers today. The driver issues a
  `fence iorw,iorw` after each CSR write sequence and relies on the RTL's
  per-write `cfg_update` pulse, but a metastability hazard still exists.
  Keep the accelerator quiescent (STATUS.busy=0) when reprogramming.
- **WRAPPER-003** - `reg_temporal_mode` is 2 bits in the CSR but only 1 bit
  is wired into the core. Modes 2, 3, 5 currently alias to mode 0/1.
- **WRAPPER-004** - SSF weights are tied to zero. Weight-load path
  (`e_rodnet_weight_write`) reaches the ConvFormer / detection heads only.
